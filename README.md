# butian — 补天白帽作战仓库

一套从「补天平台选目标」到「漏洞确认 + 报告提交 + 简历落地」的完整工作流。

不是教程，是我的实际操作台。每条命令都能直接跑。

## 这套东西解决什么

1. 补天平台上**哪些资产是真能打、且打了合法**的
2. 拿到目标后**资产怎么收干净**（子域/端口/接口/老系统）
3. **哪类漏洞性价比最高**，怎么测
4. 报告**怎么写才能过审不被降级**
5. 收益怎么变成**简历上的条目**

## 目录

```
butian/

├── tools/         # 自写扫描器

└── logs/          # 运行记录（不入库）
```

## 三条红线（写在这里是因为它会毁掉你所有成果）

1. **只打补天平台上明确列出的资产**。平台上没有的域名，一个字节都不要碰。
2. **只读不写**。看到数据库不删表、看到上传点不传马、看到用户数据只截图脱敏不下载。
3. **敏感字段一律打码**。手机号中间四位、身份证中间八位，只证明「能读到」，不证明「读了多少」。

违了任何一条，你的收获从「简历加分」变成「刑事案件」。

## 快速开始

```bash
# 1. 看方法
cat docs/01-补天作战手册.md
cat docs/03-信息收集SOP.md

# 2. 装环境
bash docs/02-环境搭建.md

# 3. 拿到一个授权目标后
bash recon/full_recon.sh target.com

# 4. 开挖
cat docs/04-漏洞挖掘SOP.md

# 5. 出洞了写报告
cp reports/template-unauthed.md reports/2026-xx-target-unauthed.md
```
